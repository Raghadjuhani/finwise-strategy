# The Bet · FinWise

> Module 1 · Ignite a PLG Motion. The growth hypothesis and where you're betting, plus the growth-loop visualization.

## Growth hypothesis

If we change sign-up and onboarding to be personalized based on user type and deliver a fast, clear result using the user's own real data, then Trial→Paid conversion will increase, because the Aha moment — a specific, real insight the user can immediately see is *theirs* — is what proves value, and proven value is what earns a purchase decision.

_____

## The bet

**We're betting on:** personalization and speed-to-result, not acquisition volume or price. Specifically — a short quiz at sign-up that identifies user type (e.g., biggest financial question: cash flow, budgeting, or fundraising prep) so the first model shown is the *right* model for that business, combined with a lean onboarding path that gets from sign-up to that personalized first result as fast as possible, on the user's own real data.

**We are deliberately NOT:**
- Showing a generic, one-size-fits-all first model — a relevant result matters more than a fast-but-generic one.
- Adding a permanent free tier (freemium) — premature at our current stage; it would mask the value problem instead of forcing us to solve it.
- Spending further on paid acquisition to compensate for a leaky funnel — we fix the leak before we pour more in.
- Building a full feature-tour or multi-step onboarding — anything that delays the personalized first result is cut.
- Changing price — this is a personalization and packaging bet, not a "charge more/less" bet.

_____

## Growth loop
