# The Mechanic · FinWise

> Module 3 · Retention & Engagement. The engagement mechanic that builds the habit loop, with rationale and a wireframe.

## The mechanic

Trigger: A weekly digest (“Your Q4 cash position updated — see what changed”) that starts as an external notification and, with repeated use, becomes internal — the owner’s own recurring question of “how’s my cash flow?” that FinWise becomes the default answer to.

Action: The smallest possible step toward a result — import one more data source, or adjust one assumption in an existing model. Kept to a single tap/field, consistent with the lean-onboarding principle: smallest step to value, not the most features shown.

Reward: A variable reward tied to real data, not manufactured randomness — each import or model update surfaces something specific and slightly unpredictable, like “Your runway extended by 3 weeks” or “This expense category grew 12% since last quarter.” The content varies because the underlying data varies. No badges, streaks, or leaderboards — those fit consumer habit apps, not a tool making real financial decisions.

Investment: Each imported data source and each model built sharpens future insights (value compounds over time), and inviting a collaborator (accountant/bookkeeper) embeds FinWise into a relationship the user doesn’t want to disrupt — the same action that powers Expand in the Invite-Driven Reverse-Trial Loop.

_____

## Rationale

Why this drives retention before the paywall.

Retention has to be earned before conversion is asked for, a user who’s built a habit around checking their real financial position has already proven the product’s value to themselves, which is what makes the paywall (placed at the moment they complete their first model) land as a natural next step rather than an interruption. This also directly targets our current weak point: 40% one-year retention. A trigger→action→reward→investment loop built on the user’s own data means each cycle makes the product harder to leave (Investment) and more relevant to return to (Trigger), rather than relying on top-of-funnel acquisition to keep replacing churned users.

Action and Investment aren’t new mechanics. Action is the same behavior as trial Activation (import/model), and Investment is the same as Expand in the growth loop (invite a collaborator). This mechanic doesn’t add a separate gamification layer; it tightens the loop that’s already the plan
